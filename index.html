💡 Cách lấy Gemini API Key (miễn phí)
1. Mở aistudio.google.com/app/apikey
2. Đăng nhập Google → bấm Create API key
3. Copy key (dạng AIzaSy... hoặc AQ.Ab8RN6...) → dán vào ô trên.

Lưu ý: Key được lưu trong localStorage của trình duyệt bạn. Không chia sẻ file HTML có key cho người khác.
